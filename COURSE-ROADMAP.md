## COURSE COMPLETION GOAL

By completing this course, the student should be able to:

- Understand and administer Linux systems.
- Work confidently with the Linux terminal.
- Manage files, users, permissions and processes.
- Configure and troubleshoot Linux networking.
- Write Bash scripts for automation.
- Secure and harden Linux systems.
- Understand firewalls and intrusion detection systems.
- Use Linux tools in authorised cybersecurity labs.
- Perform structured penetration-testing exercises.
- Document technical findings professionally.

**Important:** All cybersecurity practical exercises must be performed only on systems you own or have explicit permission to test.
