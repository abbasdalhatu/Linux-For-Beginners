
# CYBERSECURITY TOOLS REFERENCE

## 1. Introduction

Cybersecurity tools help professionals monitor, investigate, test, and protect computer systems and networks.

Tools should only be used on systems you own or have permission to assess.

## 2. Network Discovery and Analysis

### Nmap
Purpose: Network discovery and port scanning.

Common uses:
- Discover devices on an authorized network.
- Identify open ports.
- Identify running services.

### Wireshark
Purpose: Network traffic analysis.

Common uses:
- Capture network packets.
- Inspect network protocols.
- Troubleshoot network communication.

## 3. Web Security Testing

### Burp Suite
Purpose: Web application security testing.

Common uses:
- Inspect HTTP and HTTPS requests.
- Analyze web application responses.
- Test application security within an authorized scope.

### OWASP ZAP
Purpose: Web application vulnerability testing.

Common uses:
- Identify potential web vulnerabilities.
- Inspect HTTP traffic.
- Perform authorized security assessments.

## 4. Vulnerability Assessment

### OpenVAS
Purpose: Vulnerability scanning.

Common uses:
- Identify known vulnerabilities.
- Generate security reports.
- Support vulnerability management.

### Nessus
Purpose: Vulnerability assessment.

Common uses:
- Identify outdated software.
- Detect security weaknesses.
- Review configuration problems.

## 5. Penetration Testing

### Metasploit Framework
Purpose: Security testing and controlled exploitation.

Common uses:
- Validate vulnerabilities in authorized labs.
- Understand exploitation techniques.
- Test security defenses.

## 6. Password Security

### John the Ripper
Purpose: Password security auditing.

Common uses:
- Audit password strength.
- Test password hashes in authorized environments.
- Demonstrate password security weaknesses.

## 7. Digital Forensics

### Autopsy
Purpose: Digital forensic investigation.

Common uses:
- Examine disk images.
- Recover relevant digital evidence.
- Analyze files and metadata.

### FTK Imager
Purpose: Forensic imaging and evidence acquisition.

Common uses:
- Create forensic disk images.
- Examine storage devices.
- Preserve digital evidence.

## 8. Security Monitoring

### Snort
Purpose: Network intrusion detection and prevention.

Common uses:
- Detect suspicious network traffic.
- Apply detection rules.
- Generate security alerts.

### Windows Defender Firewall
Purpose: Host-based network protection.

Common uses:
- Control incoming connections.
- Control outgoing connections.
- Restrict network access.

## 9. Choosing the Right Tool

| Task | Tool |
|---|---|
| Network discovery | Nmap |
| Packet analysis | Wireshark |
| Web security testing | Burp Suite |
| Web vulnerability scanning | OWASP ZAP |
| Vulnerability assessment | OpenVAS |
| Penetration testing labs | Metasploit |
| Password auditing | John the Ripper |
| Digital forensics | Autopsy |
| Network intrusion detection | Snort |
| Windows firewall management | Windows Defender Firewall |

## 10. Important Security Rules

1. Obtain permission before testing systems.
2. Use isolated virtual machines for practical exploitation exercises.
3. Never test public systems without authorization.
4. Keep security tools updated.
5. Protect collected evidence and sensitive information.
6. Document findings and recommend fixes.

## 11. Summary

Cybersecurity tools support different security activities, including network analysis, vulnerability assessment, penetration testing, digital forensics, and security monitoring.

Understanding what each tool does is more important than simply memorizing its name.
