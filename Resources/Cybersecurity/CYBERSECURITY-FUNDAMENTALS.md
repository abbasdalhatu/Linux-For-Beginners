
# CYBERSECURITY FUNDAMENTALS

## 1. What Is Cybersecurity?

Cybersecurity is the practice of protecting computers, networks, applications, and data against unauthorized access, attacks, damage, and theft.

Its main goal is to keep digital systems secure.

## 2. The CIA Triad

The CIA Triad is a fundamental cybersecurity model.

### Confidentiality
Ensures that information is accessible only to authorized people.

Example: Encrypting sensitive files.

### Integrity
Ensures that information remains accurate and is not changed without authorization.

Example: Using file hashes to detect modifications.

### Availability
Ensures that systems and information remain accessible when needed.

Example: Maintaining backups and preventing denial-of-service attacks.

## 3. Types of Cybersecurity

- Network Security: Protects computer networks.
- Application Security: Protects software and applications.
- Information Security: Protects sensitive information.
- Cloud Security: Protects cloud-based systems.
- Endpoint Security: Protects computers and mobile devices.
- Identity and Access Management: Controls user identities and permissions.
- Operational Security: Protects systems through secure processes.

## 4. Common Cyber Threats

### Malware
Malicious software designed to damage, disrupt, or gain unauthorized access to systems.

Examples:
- Viruses.
- Worms.
- Trojans.
- Ransomware.
- Spyware.

### Phishing
A technique that tricks people into revealing sensitive information or opening malicious links.

### Social Engineering
Manipulating people into performing actions that compromise security.

### Denial of Service (DoS)
An attack that attempts to make a service unavailable by overwhelming or disrupting it.

### Password Attacks
Attempts to obtain or guess passwords without authorization.

### Man-in-the-Middle (MITM)
An attack where an attacker intercepts or potentially modifies communication between parties.

## 5. Vulnerability, Threat and Risk

- Vulnerability: A weakness in a system.
- Threat: Something capable of exploiting a weakness.
- Risk: The possibility and impact of a threat exploiting a vulnerability.

Example:

An outdated web server may contain a vulnerability. An attacker may exploit it, creating a risk of unauthorized access or data theft.

## 6. Authentication and Authorization

### Authentication
Verifies who a user is.

Example: Logging in with a password.

### Authorization
Determines what an authenticated user is allowed to do.

Example: A normal user cannot access administrator-only settings.

## 7. Multi-Factor Authentication

MFA requires two or more different authentication factors.

Common factors:

- Something you know: Password or PIN.
- Something you have: Security key or authenticator device.
- Something you are: Fingerprint or facial recognition.

MFA makes unauthorized account access more difficult.

## 8. Encryption and Hashing

### Encryption
Transforms readable information into ciphertext using a cryptographic key.

Encryption is designed to be reversible with the appropriate key.

### Hashing
Transforms data into a fixed-length digest.

Hashing is generally one-way and is commonly used for integrity verification and password storage.

Examples:
- SHA-256.
- SHA-512.

## 9. Basic Security Practices

- Use strong, unique passwords.
- Enable MFA.
- Install software updates.
- Use reputable security software.
- Back up important data.
- Avoid suspicious links and attachments.
- Apply least privilege.
- Secure Wi-Fi networks.
- Monitor system activity.

## 10. Cybersecurity Roles

- Security Analyst.
- Penetration Tester.
- Security Engineer.
- Incident Responder.
- Digital Forensics Analyst.
- Security Consultant.
- Security Architect.

## 11. Ethical and Legal Responsibilities

Cybersecurity testing must be authorized.

Always:
- Obtain permission before testing systems.
- Respect privacy.
- Avoid unauthorized access.
- Protect information discovered during testing.
- Document findings responsibly.
- Follow applicable laws and policies.
