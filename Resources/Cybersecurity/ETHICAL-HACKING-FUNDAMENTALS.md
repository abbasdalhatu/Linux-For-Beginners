
# ETHICAL HACKING FUNDAMENTALS

## 1. What Is Ethical Hacking?

Ethical hacking is the authorized practice of testing computer systems, applications, and networks to identify security weaknesses.

Ethical hackers use security testing techniques to help organizations improve their defenses.

## 2. Ethical Hacking vs Malicious Hacking

| Ethical Hacking | Malicious Hacking |
|---|---|
| Requires authorization | Lacks proper authorization |
| Follows an agreed scope | Ignores agreed boundaries |
| Aims to improve security | May aim to steal, damage, or disrupt |
| Documents findings responsibly | May hide malicious activity |

## 3. Types of Hackers

### White Hat
A security professional who tests systems with authorization.

### Black Hat
A person who accesses or attacks systems maliciously or without authorization.

### Grey Hat
A person who may identify weaknesses without authorization but does not necessarily have malicious intentions. Unauthorized access is still not automatically legal or ethical.

## 4. Types of Security Testing

### Black Box Testing
The tester has little or no prior knowledge of the target system.

### White Box Testing
The tester has detailed knowledge of the system, such as source code and architecture.

### Grey Box Testing
The tester has partial knowledge of the system.

## 5. Phases of Ethical Hacking

### Phase 1: Planning and Authorization
Define the scope, objectives, permitted methods, and testing boundaries.

### Phase 2: Reconnaissance
Collect information about the authorized target.

### Phase 3: Scanning and Enumeration
Identify exposed services, network details, and potential weaknesses.

### Phase 4: Vulnerability Analysis
Review findings to determine possible security weaknesses.

### Phase 5: Controlled Exploitation
Where explicitly permitted, safely validate whether a weakness can be exploited.

### Phase 6: Reporting
Document findings, evidence, risks, and recommendations.

### Phase 7: Remediation and Retesting
Help confirm that identified weaknesses have been corrected.

## 6. Common Ethical Hacking Tools

| Tool | Purpose |
|---|---|
| Nmap | Network discovery and port scanning |
| Wireshark | Network packet analysis |
| Burp Suite | Web application security testing |
| OWASP ZAP | Web application security testing |
| Metasploit | Authorized security validation |
| Nikto | Web server security checks |
| OpenVAS | Vulnerability assessment |
| John the Ripper | Password security auditing |

Use these tools only within systems and activities you are authorized to test.

## 7. Important Ethical Hacking Skills

- Networking fundamentals.
- Linux administration.
- Windows administration.
- Programming and scripting.
- Web technologies.
- Database fundamentals.
- Security concepts.
- Report writing.
- Critical thinking.

## 8. Rules of Engagement

Before starting a penetration test, establish:

- Written permission.
- Target systems and IP ranges.
- Testing dates and times.
- Approved techniques.
- Excluded systems.
- Emergency contacts.
- Data handling requirements.
- Reporting expectations.

## 9. Ethical Responsibilities

An ethical hacker must:

- Respect privacy.
- Protect confidential information.
- Avoid unnecessary disruption.
- Follow the agreed scope.
- Report findings accurately.
- Avoid unauthorized access.
- Securely handle collected evidence.
