
# LINUX FOR BEGINNERS
## Practical Exercises

Welcome to the practical exercises section of Linux for Beginners.

This section contains hands-on activities designed to help learners develop practical Linux, networking, cybersecurity, Bash scripting, and system administration skills.

The exercises are arranged from foundational concepts to more advanced practical tasks.

## Recommended Learning Order

For beginners, follow this sequence:

1. Linux Basics
2. Networking
3. Cybersecurity
4. Bash Scripting
5. System Administration

Intermediate learners can review the fundamentals and focus on the practical challenges.

Advanced learners can use the exercises to test their knowledge, identify gaps, and develop their own laboratory projects.

## How to Use These Exercises

1. Study the relevant topic in the Resources folder.
2. Open its corresponding exercise file.
3. Attempt each task independently.
4. Practise commands in a Linux virtual machine.
5. Research concepts you do not understand.
6. Complete the final challenges.
7. Review your progress using the completion checklists.

## Important Safety Guidelines

- Practise only on systems you own or have explicit permission to test.
- Use virtual machines for cybersecurity experiments.
- Avoid running unfamiliar commands with root privileges.
- Never expose passwords, credentials, or sensitive information.
- Do not perform unauthorized security testing.

## Learning Philosophy

The objective is not simply to memorize Linux commands.

Learners should understand what commands do, why they are useful, when to apply them, and how to troubleshoot problems.

**Learn. Practise. Understand. Build.**
