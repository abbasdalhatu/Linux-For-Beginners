
# CYBERSECURITY — PRACTICAL EXERCISES

Welcome to the Cybersecurity practical exercises.

These activities introduce learners to security principles, threat identification, ethical hacking, and defensive security.

**Difficulty:** Beginner to Advanced

IMPORTANT: Conduct practical security testing only on systems you own or have explicit permission to assess.

## Exercise 1: Cybersecurity Fundamentals

Answer the following:

1. What is cybersecurity?
2. What is information security?
3. Explain the CIA triad.
4. What is confidentiality?
5. What is integrity?
6. What is availability?
7. What is authentication?
8. What is authorization?
9. What is a security vulnerability?
10. What is a security threat?

## Exercise 2: Common Cyberattacks

Explain the following attacks:

1. Phishing.
2. Malware.
3. Ransomware.
4. Denial of Service (DoS).
5. Distributed Denial of Service (DDoS).
6. SQL Injection.
7. Cross-Site Scripting (XSS).
8. Brute-force attacks.
9. Man-in-the-Middle attacks.
10. Social engineering.

For each attack, explain:
- How it works at a high level.
- Its potential impact.
- One way to prevent or reduce its risk.

## Exercise 3: Password Security

Tasks:

1. Explain what makes a password strong.
2. Explain why password reuse is dangerous.
3. Describe multifactor authentication.
4. Explain password hashing.
5. Explain the difference between hashing and encryption.

Practical activity:

Create three example passwords using fictional information. Evaluate their strength without using your real passwords.

## Exercise 4: Ethical Hacking

Answer the following:

1. What is ethical hacking?
2. What is the difference between ethical and malicious hacking?
3. Explain white-hat hacking.
4. Explain black-hat hacking.
5. Explain grey-hat hacking.
6. What is penetration testing?
7. Why is written authorization important?
8. What are rules of engagement?

## Exercise 5: Reconnaissance and OSINT

Use only your own domain, a domain you control, or a designated training domain.

Tasks:

1. Explain passive reconnaissance.
2. Explain active reconnaissance.
3. Perform a DNS lookup using nslookup.
4. Identify common DNS record types.
5. Explain what WHOIS and RDAP are used for.
6. Explain how public information can help security professionals identify risks.

Commands:

```bash
nslookup example.com
nslookup -type=MX example.com
nslookup -type=NS example.com
```

## Exercise 6: Vulnerability Assessment

Answer the following:

1. What is vulnerability assessment?
2. What is vulnerability scanning?
3. What is a false positive?
4. What is a false negative?
5. What is the purpose of CVE identifiers?
6. What does CVSS measure?
7. Why should vulnerabilities be prioritized?
8. Explain the difference between vulnerability assessment and penetration testing.

## Exercise 7: Windows Security

On your own Windows computer:

1. Open Windows Security.
2. Check Microsoft Defender Antivirus status.
3. Check Firewall and network protection.
4. Open Windows Update.
5. Open Event Viewer.
6. Identify the main Windows event log categories.

Useful commands:

```cmd
tasklist
netstat -ano
systeminfo
whoami
```

Do not disable security protections during this exercise.

## Exercise 8: Security Incident Investigation

Scenario:

A user receives an email claiming their university account will be suspended unless they click a link immediately.

Questions:

1. What warning signs might indicate phishing?
2. What should the user avoid doing?
3. How should the message be reported?
4. What should the user do if they already entered their password?
5. Why is multifactor authentication useful?

## Exercise 9: Defensive Security Challenge

Create a basic security checklist for a personal Windows computer.

Include:
- Antivirus protection.
- Firewall configuration.
- Operating system updates.
- Password security.
- Data backups.
- Application security.
- Account protection.
- Safe browsing habits.

## Exercise 10: Advanced Knowledge Assessment

1. Explain the CIA triad with examples.
2. Describe the stages of an authorized penetration test.
3. Explain how vulnerability severity is assessed.
4. Compare passive and active reconnaissance.
5. Explain the role of IDS and IPS.
6. Describe how incident response works.
7. Explain why security documentation matters.
8. Describe responsible vulnerability disclosure.
