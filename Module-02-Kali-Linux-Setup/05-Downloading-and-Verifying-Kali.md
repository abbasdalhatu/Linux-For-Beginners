# LESSON 05: DOWNLOADING AND VERIFYING KALI LINUX

**Module:** 02 – Kali Linux Setup  
**File:** `05-Downloading-and-Verifying-Kali.md`

## 1. Introduction

Before installing Kali Linux in VMware, we need to download its installation image.

Kali Linux is distributed as an ISO file.

An ISO file is a disk image containing the files required to install or run an operating system.

For this course, we will use the **64-bit Installer ISO (AMD64)**.

Why AMD64?

Your Dell Latitude 7320 uses an Intel Core i7 processor. Although the name says AMD64, this architecture supports modern 64-bit Intel and AMD processors.

## 2. Understanding Kali Linux Download Options

Kali provides different download options.

| Download type | Purpose |
|---|---|
| Installer ISO | Installs Kali Linux on a computer or VM |
| Live ISO | Runs Kali without installing it |
| Virtual Machine Image | Prebuilt Kali VM for supported hypervisors |
| NetInstaller | Installs packages through the internet |

For this course, we will use the **Installer ISO** so that we learn the installation process ourselves.

## 3. Download Kali Linux

### Step 1: Open the official website

Visit:

https://www.kali.org/get-kali/

Only download Kali from the official Kali Linux website.

### Step 2: Select the Installer image

1. Locate the Installer section.
2. Select the 64-bit (AMD64) Installer ISO.
3. Start the download.
4. Save the ISO inside your Windows Downloads folder.

Do not download the ARM64 image. Your laptop uses the Intel/AMD-compatible x86-64 architecture.

## 4. Understanding File Integrity

After downloading an ISO file, we need to verify that it has not been corrupted or modified.

Two important concepts are:

**Integrity:** Confirms that a file has not changed unexpectedly.

**Authenticity:** Helps establish that a file came from the legitimate publisher.

We will use SHA-256 hashing and compare the result with Kali's officially published checksum.

## 5. Understanding SHA-256

SHA-256 is a cryptographic hash function.

It takes data of any supported size and produces a fixed-length 256-bit hash, usually displayed as 64 hexadecimal characters.

Example:

`hello`

A SHA-256 function produces a fixed-length hash for this input.

If even one character changes, the resulting hash will be dramatically different.

This makes SHA-256 useful for detecting file changes.

## 6. Verify the ISO Using Windows CMD

After the download finishes:

1. Open Command Prompt.
2. Navigate to your Downloads directory:

```cmd
cd %USERPROFILE%\Downloads
```

3. List your downloaded files:

```cmd
dir *.iso
```

4. Calculate the SHA-256 hash:

```cmd
certutil -hashfile kali-linux-installer-amd64.iso SHA256
```

Replace `kali-linux-installer-amd64.iso` with the exact filename shown on your computer.

Windows will display a SHA-256 hash.

## 7. Compare the Checksum

Return to the official Kali download page.

Find the SHA-256 checksum published for the exact ISO version you downloaded.

Compare it with the hash generated by CMD.

**Important:** Both hashes must match exactly.

- If they match, the downloaded file passes the checksum comparison.
- If they do not match, do not use the ISO. Check the filename and download it again from the official website.

For stronger authenticity verification, Kali also provides signed checksum files. A checksum comparison alone does not prove who published the checksum.

## 8. Important Security Rules

1. Download Kali only from official sources.
2. Never run unknown ISO files.
3. Verify the SHA-256 checksum before installation.
4. Never install Kali directly on your Windows host for this course.
5. We will install Kali inside VMware.
6. Keep your Windows security protections enabled.
